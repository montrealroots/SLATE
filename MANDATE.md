# The Mandate For The New SLATE

The owner's standing instruction for the rebuild, given 2026-10-26, kept in their own words first and then as the
rules the build is held to. It governs every file in this package and every commit of the new repository.

## The owner's words

> This should be completed perfectly and 100% from end to end. Every single feature on every single page should
> read, bite, and have downstream effects. I want 0 decorations, meaning nothing should be there for show at all;
> everything needs to 100% perfectly read, bite, and have a downstream effect. I want the complete coverage matrix
> and coverage research for each feature, and I want every one 100% covered, so no stopping until it's done and no
> half facts: do whatever it takes to find it. It will retain the most perfect and beautiful UI and navigation
> system known to man. Build my code from top to bottom in the proper perfect order, just how it should be, and

And from earlier the same day, still in force: a natural, coherent and realistic voice in every word the game says;
real engines researched to the source behind every field, Billed As and race or ethnicity included; whatever reads a
place covers the whole map built into the game; the School, the career, the attributes, the dispositions, the
tutorial and the manual are out of the first build; and no merge or deployment without the owner's word.

## The rules, as the build is held to them

1. **Read, bite, downstream.** Every feature on every page reads real state, changes real state when acted on,
   and is read in turn by something else that changes an outcome the player meets. A feature that fails any of
   the three is not built. The proof is mechanical: a feature-to-effect matrix with a consumer at a file and line
   for every feature, and the falsifiability test on every claim (change the input; the outcome changes, not only
   the sentence). The gate that checks both runs on every commit and fails the build on a miss.
2. **Zero decoration.** Nothing shown that nothing reads, nothing asked that nothing uses, no number typed where a
   sum belongs, no choice that ends the same whichever way it's made, no text that explains instead of does.
3. **Full coverage, researched.** Every engine has a coverage matrix; every engine that reads a place covers all
   252 countries and territories and 170,911 places; every row cites the primary source and the date it was read,
   in a research register the gate holds; a row without its source fails. Where a source cannot be reached after
   everything (web search in every phrasing, the institution's own site and documents, official registers, trade
   press quoting a primary source, archived copies), the row records the blocker by name and date, the game tells
   the player what isn't modeled, and nothing is invented. No half facts: a figure from memory or a summary is not
   a figure.
4. **No stopping until it's done.** Done is the whole matrix covered and the gate green from end to end, not a
   first screen that works. Work is checkpointed so an interruption resumes, never restarts.
5. **The UI and the navigation.** The look this SLATE built (its tokens, its type, its spacing, its dark field and
   gold accent, its one-card-per-thing pages, its menu and top bar) is the starting standard, to be refined into the
   best interface and navigation the owner has seen, never cluttered: every control earns its place by rule 1, and
   every screen reads in the order a person would ask its questions.
6. **Built in the proper order, top to bottom.** See `BUILD-ORDER.md`: the foundations first, each proven before
   the next is laid on it, so nothing is built on a guess.
7. **Connected, cohesive, logical.** One model of the world, every system reading the same state through the same
   engines, no second copy of a fact anywhere; dates, money, places, papers and history never contradict one
   another, and a test holds each such invariant.
8. **The voice.** Natural, coherent and realistic in every word the game says, with the engine's vocabulary kept
   out of the player's sight (`KEEP.md`, entry 2).

## What the owner decides

The premise (what the life is a life of), home on the first morning, the start date, whether Sleep stays as a clock
action, the final wording of every screen, and where the clean repository lives. Everything else in this package is
decided, and the register (`KEEP.md`) says where and when.
