# SLATE

An actor/actress life simulator, rebuilt from the owner's package in `docs/`. Start with `CLAUDE.md`, then the
package in the order it gives, then `HANDOFF.md` for where the build stands.

## Running it

Node 22.22.0 (`.nvmrc`). Install with `npm ci`. Adding or changing a dependency needs npm 11.6.2 (`packageManager`):
`npx -y npm@11.6.2 install -E <package>@<version>`, since npm 10's resolver crashes on this tree.

- `npm run gate`: the gate, as every commit runs it: the toolchain pins, the owner's documents, the build order,
  the text inventory, the research register, the typecheck, the lint, the tests, the feature-to-effect matrix, the
  coverage matrices and the handoff. Exit 0 green, 1 red (a rule broken), 2 incomplete (declared work unfinished).
- `npm run gate:full`: the same plus mutation testing; a layer is proven only on a green full gate.
- `npm run gate:write`: rewrites the generated matrices in `matrix/` from what the checks find.
- `npm run lock:owner-docs`: re-locks the owner's documents; only with a change the owner made.

## Where things are

| Path | What |
|---|---|
| `docs/` | The owner's package: mandate, build order, screens, the keep register, captures, kept source. Locked. |
| `gate/` | The gate: its checks, its lint rules, its tests. |
| `registry/` | What the gate holds the build to: layers, pages, features, engines, axes, the voice rules. |
| `research/register.json` | The research register: every fact, its source and the date it was read, or its blocker. |
| `coverage/` | One coverage matrix per engine axis. |
| `matrix/` | Generated by the gate for reading: layers, features, coverage, the register in brief, the text inventory. |
| `src/` | The game, by layer: `core`, `world`, `papers` and `money`, `person`, `ui` and `app`. |
| `tests/` | The game's tests; `tests/support/falsify.ts` records each falsifiability proof for the gate. |
