# SLATE

An Actor/Actress Life Simulator.

This repository starts from the package the owner decided on 2026-10-26, carried over from the first SLATE. Read in
this order before writing any code:

1. `MANDATE.md`: the owner's standing instruction, in their words and as the rules the build is held to.
2. `BUILD-ORDER.md`: the code's order, foundations first, each layer proven before the next.
3. `SCREENS.md`: the first build's screens in the player's order, each as a full page.
4. `KEEP.md`: the register, one numbered entry per decision, with every detail and the owner's words.
5. `captures/01-opening/`: the first SLATE's pages as they stood, which the decisions were made from.
6. `captures/02-new-build/`: the first build's pages as decided, rendered from the first SLATE with the cuts and
   moves applied, and the scripts that made them.
7. `kept/`: verbatim copies of the first SLATE's source behind each kept thing, the reference to rebuild from; they
   import paths of that repository and are not files to drop in unchanged.
